# QAuthburgerkayson

A custom C++ authentication application featuring TOTP token generation, a secure data store, and QR code scanning capabilities.

## 🔒 Security & Verification

To verify the safety of the application executable, you can check the independent analysis report here:
* [VirusTotal Scan Report](https://virustotal.com)

*Note: Because the standalone executable available in the Releases section is unsigned, Windows SmartScreen may trigger a "Windows protected your PC" pop-up. You can safely bypass this by clicking **More Info** and then **Run Anyway**, or compile the raw source code yourself.*

## 🚀 How to Build from Source

If you prefer to compile the application yourself, use a C++ compiler supporting C++17 or later:

1. Clone the repository:
   ```bash
   git clone https://github.com/burgerkayson-collab/QAuthburgerkayson.git
   cd QAuthburgerkayson
   ```
2. Compile the source files with your preferred compiler framework (e.g., GCC/MinGW, MSVC, or Qt Creator toolchains).
